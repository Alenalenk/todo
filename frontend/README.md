📝 Todo List App

Простий та мінімалістичний застосунок для керування задачами (Todo List), створений з використанням сучасного React-стеку. Дозволяє додавати, видаляти та відмічати задачі як виконані.

🚀 Технології
React — побудова інтерфейсу
TypeScript — типізація та безпечніша розробка
RTK Query — робота з API та кешування даних
React Hook Form — зручна робота з формами
CSS Modules — модульна стилізація компонентів

✨ Функціонал
➕ Додавання нових задач
✔️ Позначення задач як виконаних / невиконаних
🗑️ Видалення задач
🔄 Синхронізація з API через RTK Query
⚡ Оптимізований state management через Redux Toolkit
🎯 Валідація форм через React Hook Form

📦 Запуск проєкту
npm install
npm run dev

або

yarn install
yarn dev

Для роботи додатку в корневу папку необхідно додати .env, де вказати адресу backend
VITE_BASE_URL=http://127.0.0.1:8082
